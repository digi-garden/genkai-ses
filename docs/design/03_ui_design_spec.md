# 03 UIデザイン仕様

> 版：1.0（2026-10-31） ／ 対象要件：`requirements_v1.12.md`（4.1、7.1） ／ 関連：`02_screen_design.md`、`10_mockup`（デザインキャンバス）
> 目的：見た目と手触りを統一する。実装では、本書の値を Tailwind の `@theme`（`src/styles/theme.css`）にそのまま定義する。

---

## 1. デザインの方向性

- **「深夜の社内チャット」**：Slack / Discord 風のダークなビジネス UI（要件 4.1）。カードは上司や客からの「メッセージ」として見せる。
- 色は、緑（正常・決断）、アンバー（社長の切り札・因果応報）、赤（危険）の3つの意味だけに使う。それ以外は灰色の濃淡で組む。
- 装飾（グラデーション、影の多用、絵文字）は使わない。ドット絵の話者アイコンと結末の一枚絵が、唯一の「絵」になる。

## 2. 色

### 2.1 色のトークン

| トークン | 値 | 用途 |
|---|---|---|
| `bg` | `#1E1F22` | 画面の背景（要件指定） |
| `surface` | `#2B2D31` | ヘッダー、フッター、モーダル |
| `card` | `#313338` | イベントカード、入力欄 |
| `border` | `#3F4147` | 区切り線、カードの枠 |
| `border-strong` | `#4E5058` | 入力欄の枠、ボタンの枠 |
| `text` | `#F2F3F5` | 本文 |
| `text-muted` | `#B5BAC1` | 補足、話者の役職 |
| `text-subtle` | `#949BA4` | 注記、キーの操作ヒント |
| `primary` | `#22C55E` | 決断ボタン、正常なゲージ、強調（要件指定のターミナルグリーン） |
| `on-primary` | `#0B1A10` | 緑の上の文字 |
| `danger` | `#EF4444` | 危険域のゲージ、倒産の演出（**塗りにだけ使う**。要件指定） |
| `danger-text` | `#F87171` | 赤い文字（`danger` は文字にするとコントラストが足りないため） |
| `accent` | `#F59E0B` | 社長の切り札、【因果応報】バッジ、称号 |
| `on-accent` | `#1E1F22` | アンバーの上の文字 |
| `focus` | `#60A5FA` | キーボード操作時のフォーカス枠 |

### 2.2 コントラストの確認結果（WCAG 2.1。文字は 4.5:1 以上が必要）

| 前景 \ 背景 | `bg` | `surface` | `card` |
|---|---|---|---|
| `text` | 14.8 | 12.4 | 11.4 |
| `text-muted` | 8.4 | 7.1 | 6.5 |
| `text-subtle` | 5.9 | 4.9 | 4.5 |
| `primary` | 7.2 | 6.1 | 5.6 |
| `danger-text` | 6.0 | 5.0 | 4.6 |
| `accent` | 7.7 | 6.4 | 5.9 |
| `danger`（参考：文字には使わない） | 4.4 | 3.7 | 3.4 |

- 緑の上の `on-primary`：7.9、アンバーの上の `on-accent`：7.7。
- `text-subtle` を `card` の上で使うのは 4.5 ちょうどなので、`card` の上の注記は `text-muted` を使う。
- **色だけに頼らない：** 正常（緑）と危険（赤）は明るさも違う（相対輝度 0.41 と 0.23）。さらに、危険域ではゲージの枠を点滅させ、形でも区別できるようにする。

## 3. 文字

### 3.1 フォント

```css
font-family: 'GenkaiMono', ui-monospace, 'Hiragino Sans', 'Noto Sans JP', monospace;
```

- `GenkaiMono` は、M PLUS 1 Code をビルド時にサブセット化したもの（01 の D6、09 検証2）。太さは 400 と 700 の2種類だけを用意する。
- モックアップでは、Google Fonts の M PLUS 1 Code をそのまま使う。

### 3.2 文字サイズ

| トークン | サイズ / 行の高さ | 太さ | 用途 |
|---|---|---|---|
| `display` | 28px / 1.3 | 700 | タイトル画面のゲーム名、結末名 |
| `heading` | 20px / 1.4 | 700 | 画面の見出し、モーダルの見出し |
| `message` | 17px / 1.7 | 400 | カードの本文（いちばん長く読む文字なので、行間を広く取る） |
| `body` | 15px / 1.6 | 400 | 説明文、選択肢のボタン |
| `label` | 13px / 1.5 | 700 | 話者名、ゲージのラベル、バッジ |
| `caption` | 12px / 1.5 | 400 | 注記、キー操作のヒント、免責文 |

- 最小は 12px。スマホでも拡大せずに読めるようにする。
- PC では、`message` だけ 18px に上げる。

## 4. 余白・角丸・サイズ

| 区分 | 値 |
|---|---|
| 余白の単位 | 4px（4 / 8 / 12 / 16 / 24 / 32 / 48） |
| 画面の左右の余白 | スマホ 16px、PC はゲーム領域を中央に置く（02 の 3章） |
| 角丸 | 小 6px（バッジ、入力欄）、中 10px（ボタン）、大 16px（カード、モーダル） |
| タップ領域 | 最小 44×44px（要件のアクセシビリティ） |
| ゲーム領域の最大幅 | 480px（PC でも、カードが横に間延びしないようにする） |

## 5. 部品

### 5.1 イベントカード
- 背景 `card`、枠 `border` 1px、角丸 16px、内側の余白 20px。
- 上から順に、話者アイコン（ドット絵 64×64px。`image-rendering: pixelated`）、話者名（`label`）と役職（`caption` `text-muted`）、本文（`message`）。
- 連鎖カードでは、カードの上端に【因果応報】バッジ（背景 `accent`、文字 `on-accent`、`label`）を付け、枠の色を `accent` にする。
- 導入カードでは、話者を「秘書」にし、本文の下に操作のヒント（スワイプ・キー・ボタン）を図で示す。

### 5.2 ドラッグ中の選択肢プレビュー
- カードを左右に傾けると、傾けた側の上部に、その選択肢の文言を重ねて表示する（背景 `bg` の 90% 不透明、文字 `text`、`body` の太字）。
- 傾けた量が 30px を超えたら表示し始め、80px（決定のしきい値）で完全に不透明にする。

### 5.3 ステータスゲージ（4つ）
- アイコン（44×44px の枠）の中を、下から上へ塗る（Reigns 方式）。塗りの高さ＝パラメータの値（0〜100%）。数値は表示しない（要件 3.1-1）。
- 塗りの色：通常は `primary`。値が **15以下または85以上**（危険域）のときは `danger` にし、枠を点滅させる（1秒周期）。
- アイコン：資金＝紙幣、顧客満足＝握手、現場メンタル＝人物（ハートの表情）、コンプラ＝天秤（lucide-react の `banknote` / `handshake` / `users` / `scale`）。アイコンの下に短いラベル（資金 / 顧客 / 現場 / コンプラ）を付ける。
- **予兆ドット**：アイコンの上に白（`text`）の丸を出す。変化量が小さいときは直径 6px、大きいとき（絶対値10以上）は 10px（要件 7.1-1）。増減の向きは示さない。

### 5.4 ボタン

| 種類 | 見た目 | 用途 |
|---|---|---|
| 決断ボタン | 背景 `card`、枠 `border-strong`、文字 `text`。押している間・キー操作時は枠を `primary` に | 2択（選択肢A / B） |
| 主ボタン | 背景 `primary`、文字 `on-primary`、太字 | 「経営を始める」「もう1期挑む」「Xでポスト」 |
| 副ボタン | 背景 透明、枠 `border-strong`、文字 `text` | 「画像を保存」「図鑑」など |
| 切り札ボタン | 背景 透明、枠 `accent`、文字 `accent`。確認状態では背景 `accent`・文字 `on-accent` にして点滅 | 社長の切り札 |
| 文字リンク | 文字 `text-muted`、下線 | 規約、遊び方など |

- 使えないとき（切り札を使い終えたなど）は、不透明度 40% にし、文言を「使用済み」に変える。

### 5.5 モーダル
- 背景の上に `bg` の 70% 不透明の幕を敷き、中央に `surface` のパネル（角丸 16px、最大幅 440px）を置く。スマホでは画面の下からせり上がる形（ボトムシート）にする。
- 閉じるボタン（×）は右上に置き、`Esc` キーでも閉じる。

## 6. 動き（アニメーション）

| 動き | 時間 | イージング | 備考 |
|---|---|---|---|
| カードを決定して飛ばす | 0.25秒 | ease-in | 決定のしきい値：ドラッグ量 80px、または素早く払う（速度 500px/秒以上） |
| 次のカードが現れる | 0.2秒 | ease-out | 下から 8px 浮き上がりながらフェードイン |
| ゲージの増減 | 0.3秒 | ease-out | 塗りの高さが変わる |
| 予兆ドットの出入り | 0.12秒 | linear | |
| 切り札の確認状態 | 0.15秒で切り替え、その後1秒周期で点滅 | | |
| 倒産の演出 | 0.6秒 | | 画面が一瞬暗くなり、赤い線が走る。テンポの要件（0.3秒以下）の対象外とする（ラン終了の演出のため） |

- 選択してから次のカードが操作できるまでを **0.3秒以下** に収める（要件 3.1-6）。飛ばす動きと次のカードの出現は、重ねて実行する。
- `prefers-reduced-motion: reduce` の環境では、カードの飛ばし・出現をフェードだけにし、ゲージの点滅を止める（色と枠の太さで示す）。スワイプ操作そのものは残す。

## 7. アクセシビリティ

- 文字のコントラストは 4.5:1 以上（2.2 の表）。
- キーボードだけで最後まで遊べる（02 の 4章）。フォーカス枠は `focus` 色の 2px。
- 決断ボタンと切り札ボタンは `<button>` にする。ゲージには `role="meter"` と `aria-label`（例：「資金」）を付け、`aria-valuetext` は「危険なほど低い」「やや低い」「普通」「やや高い」「危険なほど高い」の5段階の言葉で伝える（数値は出さない方針に合わせる）。
- カードの本文が変わったら、`aria-live="polite"` の領域で読み上げる。
- 話者アイコンと結末の一枚絵には、内容を表す `alt` を付ける。
