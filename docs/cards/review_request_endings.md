# 結末と称号の文言の専門家レビュー依頼（Phase 1-B）

## 渡すもの
1. `docs/cards/card_list.md` の末尾にある「結末の文言」「称号」の2つの表（必須。表だけを貼り付けてもよい）
2. 結末の一枚絵9枚（任意。`src/assets/img/end_*.webp`。絵と文言が合っているかまで見てもらう場合）

- 依頼文に、作品の概要と執筆ルールを書き込んである。要件定義書やカードの一覧は渡さなくてよい。
- カードのレビュー（`review_request_phase1a.md`）と同じく、観点をまとめて1回で頼む作りにしてある。

## 依頼文

```
あなたは次の3人の専門家として、Webゲームの「結末」と「称号」の文言をレビューしてください。
- A：コメディ・風刺の編集者（笑いの質、風刺の向き、言葉の切れ味）
- B：SNS マーケティングの担当者（X〔旧Twitter〕でシェアしたくなるか）
- C：広告審査と表現リスクに詳しい担当者（Google AdSense の審査、炎上・名誉毀損のリスク）

# 作品の概要
- タイトル『限界SES社長 〜人月ピラミッドの頂点へ〜』。ブラウザで遊ぶ無料の個人開発ゲーム。
- Reigns 型：カードに書かれた相談に、左右どちらかの選択肢で答える。
- ゲージは4つ（資金・顧客・現場・コンプラ）。初期値は50で、どれか1つでも 0 か 100 に達すると倒産する。そのため結末は8通りの倒産と、1期（52週）を生き延びる「1期完走」の計9種類ある。
- プレイヤーは SES 企業の社長。業界の構造（多重下請け、人月での値付け、無茶な仕様変更）を笑う風刺ゲーム。
- 想定するプレイヤーは IT 業界の人。1回のプレイは数分で、「あるある」で笑い、結果を X でシェアしてもらうのが狙い。

# 文言が出る場所
- 結末の「タイトル」と「一言」：結果画面の一番上。結末の一枚絵（ドット絵）の真下に、タイトル、一言の順で出る。
- 結末の「自虐コメント」：X のシェア文の3行目。倒産の原因になった選択（敗因）が特定できないときにだけ入る。シェア文は次の形になる。
    限界SES社長で第24週に全員蒸発エンド
    最終売上4,800万｜称号［スピード退職］
    全員辞めました。悪いのは全部、社長です。   ← 自虐コメント（敗因があるときは「敗因：第18週 〇〇した」）
    #限界SES社長
    （ゲームの URL）
- 称号の「条件」：図鑑に、取得条件として出る。称号はリザルトとシェア文にも名前が出る。

# 一枚絵の場面（文言と絵が合っているかの確認に使ってください）
- 黒字倒産：薄暗い社長室で、社長が白紙の通帳を見て呆然としている。作業員が家具を運び出し、机やPCに赤い差し押さえの札が貼られている。壁には右肩上がりのグラフ。
- 敵対的買収：役員2人に両脇を抱えられ、社長が札束を抱えたまま会議室から運び出される。投資家たちは笑顔で挙手の採決。上座には別の人物が座っている。
- 契約解除：冷たい会議室で、元請けの役員たちが分厚い書類の束を小さく青ざめた社長へ押しやる。窓の外は雷雲。
- 際限なき奴隷：客先のドアから白紙のチケットがベルトコンベアで流れ込み続ける。社長と技術者たちが、手首を机に鎖でつながれたまま働いている。
- 全員蒸発：夜の、誰もいない IT オフィス。モニターはついたまま、椅子は引かれたまま、飲みかけのコーヒー。1台のスマホに通知が光っている。
- 技術オタク化：燃えているカレンダー（締め切り）を無視して、技術者たちが巨大で美しく複雑すぎるサーバーとケーブルの機械を楽しそうに組み上げている。社長は隅で頭を抱えている。
- 労務監査局突入：架空の監査機関の職員（無地の腕章）が書類の段ボールを運び出していく。社長は机の向こうで固まっている。
- 官僚主義崩壊：オフィスが承認書類の山に埋もれ、社長がひたすらハンコを押している。その間に客がドアから去っていく。
- 1期完走：夜明けのオフィスの前で記念撮影。ボロボロだが誇らしげな社長、秘書、技術者たちが札束を掲げ、疲れた笑顔でピースしている。

# 執筆ルール（このルールに照らしてレビューしてください）
1. 矛先は常に構造に向ける。現場のエンジニア、新人、下請け、退職者の苦しみそのものは嘲笑しない。
2. 最大の道化はプレイヤー（社長）自身。倒産は「社長の経営判断の結果」として書き、辞めた人や客を責めない。
3. 性別・年齢・国籍・出身・障害・容姿などの属性をネタにしない。
4. 実在の企業名・サービス名・商標と、それを想起させる隠語を使わない。
5. 露骨な違法用語を使わない。「偽装請負」「二重派遣」「多重派遣」「経歴詐称」「スキル詐称」「違法派遣」「労基」「労働基準監督」「書類送検」「逮捕」は、どこにも直接書かない。
   理由：同じドメインでブランドが Google AdSense の審査を受けており、ドメイン全体の評価に影響しうるため。
6. 結末のタイトルは、要件で決めた名前のため変えない（ただし「際限なき奴隷」の「奴隷」のように、表現として強すぎる言葉は指摘してよい）。

# 観点
## A：笑いと風刺の質
- 一言を読んで、ニヤリとするか。説明的で笑いどころのないもの、オチが弱いものはどれか。改善案を出してほしい。
- 9種類のトーンがそろっているか（1つだけ真面目すぎる、1つだけふざけすぎる、などがないか）。
- 一言と自虐コメントが同じ内容の言い直しになっていて、もったいないものはないか。

## B：シェアしたくなるか
- 自虐コメントは、シェア文の3行目として、自分の結果として投稿したくなる文か。IT 業界の人が「分かる」と反応したくなるか。
- 称号の名前は、自慢したくなる、または笑って晒したくなるものか。
- 称号の条件の説明は、図鑑で読んで「狙ってみよう」と思えるほど分かりやすいか。

## C：表現のリスク
- AdSense の審査で問題になりそうな表現はあるか（特に「際限なき奴隷」「労務監査局突入」の結末）。
- 辞めた人、客先、監査機関、実在の業界団体を揶揄していると受け取られうる表現はないか。
- 絵と文言の組み合わせで、強すぎる印象になるものはないか（例：鎖の絵と「奴隷」の組み合わせ）。

## 共通：絵と文言の一致
- 一言が、一枚絵の場面と食い違っていないか（時間帯、誰がいるか、何が起きているか）。

# 文字数の目安（修正案もこの範囲で）
- 一言：50文字以内（結果画面で1〜2行に収めたい）
- 自虐コメント：25文字以内（シェア文の1行に収めたい。X の文字数制限があるため）
- 称号の条件：40文字以内

# 回答の形式
1. 全体の評価（3〜6行）：良い点と、最も直すべき点
2. 指摘の一覧（表）。重要度の高い順に並べる。

| No | 観点（A〜C・共通） | 対象（結末のID または称号の名前） | 項目（一言／自虐コメント／条件など） | 重要度（高／中／低） | 問題 | 修正案（文言まで具体的に） |
|---|---|---|---|---|---|---|

   - 重要度「高」は、公開前に必ず直すべきもの（ルール違反、AdSense や炎上のリスク、絵と矛盾している）に限ってください。
   - 修正案は、文字数の目安を守った完成形の文言で書いてください。
3. 良い文言（2〜4件）：対象と、良い理由を1行ずつ

# 注意
- 指摘の数を増やすことより、重要な指摘を確実に挙げることを優先してください。問題がない文言に無理に指摘を付けなくて構いません。
- 推測で書く場合は「推測」と明記してください。
```
