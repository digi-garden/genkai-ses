# カード62枚の専門家レビュー依頼（Phase 1-A）

## 渡すファイル
1. `docs/cards/card_list.md`：カード62枚の一覧（必須）
2. `docs/balance/2026-11-12_phase1a.md`：数値調整の記録（任意。数値まで見てもらう場合）

- 依頼文に、執筆ルールと制約を書き込んである。要件定義書は渡さなくてよい。
- 4つの観点をまとめて1回で頼む作りにしてある。回答が浅くなる場合は、「# 観点」のうち1つか2つだけを残して、観点ごとに別のAIや別の会話で頼む（これまでのレビューと同じ進め方）。

## 依頼文

```
あなたは次の4人の専門家として、Webゲームのカード（イベント文）62枚をレビューしてください。
- A：SES・受託開発業界に15年いた現場出身の経営者（業界のリアリティ）
- B：ゲームデザイナー（2択カードゲームの選択の面白さ）
- C：コメディ・風刺の編集者（笑いの質と、風刺の向き）
- D：広告審査と表現リスクに詳しい担当者（Google AdSense の審査、炎上・名誉毀損のリスク）

# 作品の概要
- タイトル『限界SES社長 〜人月ピラミッドの頂点へ〜』。ブラウザで遊ぶ無料の個人開発ゲーム。
- Reigns 型：カードに書かれた相談に、左右どちらかの選択肢で答える。
- ゲージは4つ（資金・顧客・現場・コンプラ）。初期値は50で、どれか1つでも 0 か 100 に達すると倒産する。
- 1期（52週）を生き延びるとクリアになる。1週につきカード1枚。
- プレイヤーは SES 企業の社長。業界の構造（多重下請け、人月での値付け、無茶な仕様変更）を笑う風刺ゲーム。
- 想定するプレイヤーは IT 業界の人。「あるある」で笑い、結果をX（旧Twitter）でシェアしてもらうのが狙い。
- カードの種類
  - 導入：初回だけ Week 1〜2 に出る
  - 季節固定：Week 13/26/39/52 に必ず出る
  - 通常：山札から出る。「序盤」は初回プレイで先に出る
  - 連鎖：不正な選択をすると、数週後にツケとして出る。倒産したとき、元の選択が「敗因」として表示される
- 数値は、自動プレイのシミュレーションで難しさを調整済み。数値の細かい当否は見なくてよい。ただし「この選択肢でこの数値の向きはおかしい」という指摘は歓迎する。

# 執筆ルール（このルールに照らしてレビューしてください）
1. 矛先は常に構造に向ける。多重下請けの商流、人月の値付け、無茶な仕様変更、理不尽な発注者や制度を笑う。現場のエンジニア、新人、下請け、退職者の苦しみそのものは嘲笑しない。
2. 最大の道化はプレイヤー（社長）自身。社長がうまく搾取して勝つ話にはしない。目先の金に目がくらんで自業自得の目に遭う、間の抜けた経営者として描く。
3. 違法・不正な選択肢（一覧の「⚠ 不正」）には、必ず代償の連鎖カードと敗因の文言を付ける。その場で得をしても、後で必ずツケが回る構図にする。
4. 性別・年齢・国籍・出身・障害・容姿などの属性をネタにしない。パワハラ・セクハラは、加害者側を批判的に描く場合に限る。
5. 実在の企業名・サービス名・商標と、それを想起させる隠語を使わない。登場人物は役職とステレオタイプで描く。
6. 違法行為の具体的な手口（書類の偽造方法など）は書かない。「やった」という事実と、その結果だけを描く。
7. 露骨な違法用語を使わない。「偽装請負」「二重派遣」「多重派遣」「経歴詐称」「スキル詐称」「違法派遣」「労基」「労働基準監督」「書類送検」「逮捕」は、どこにも直接書かない。業界の人がニヤリとする言い換えで描く（例：「経歴をプロデュースする」「商流が深い」「監査の立ち入り」）。
   理由：同じドメインでブランドが Google AdSense の審査を受けており、ドメイン全体の評価に影響しうるため。

# 文字数などの制約（修正案もこの範囲で書いてください）
- セリフ（message）：100文字以内
- 選択肢の文言：20文字以内
- 敗因の文言（regret_text）：30文字以内
- 話者は9人で固定：秘書 森、営業 爽やか佐藤、客先役員 権田、元請けPM 鬼塚、監査官 白石、ベテラン 古田、新人 山田、下請け社長 小林、社長（心の声）
- 連鎖カードのセリフは「（あの時、〜）」で始め、元の選択を思い出させる形にしている

# 観点
## A：業界のリアリティ
- SES・受託の現場の人が読んで「あるある」と思うか。「こんなことは起きない」「言葉の使い方が業界とずれている」カードはどれか。
- 業界の人ならすぐ思いつくのに抜けている定番ネタは何か（追加候補として。Phase 2 でカードを50枚ほど足す予定）。

## B：選択の面白さ
- 片方の選択肢が明らかに正解で、迷いの生まれないカードはどれか。
- 同じ構図（「受ける／断る」など）が続き、単調に感じられるカードはどこか。
- 不正な選択肢は「その場では魅力的」に見えているか（魅力がなければ誰も選ばず、連鎖の仕組みが働かない）。

## C：笑いと風刺の質
- 笑えるカード、ニヤリとするカードはどれか（良い例として残したい）。
- 説明的で笑いどころのないカード、オチが弱いカードはどれか。言い回しの改善案を出してほしい。
- 執筆ルール1・2に反して、弱い立場の人を笑っている、または社長が得をして終わる構図になっているカードはないか。

## D：表現のリスク
- AdSense の審査で「違法行為を助長するコンテンツ」「不快なコンテンツ」と判断されそうな表現はあるか。特に、不正な選択肢（経歴、名前だけの体制図、ライセンスの使い回し、見なし残業、客先からの直接指示、勤怠の記録を整える、深い商流）の書き方。
- 執筆ルール7の語を直接使っていなくても、言い換えが露骨すぎるもの、逆に何のことか伝わらないものはあるか。
- 実在の企業・サービス・人物を想起させる表現はないか。
- 属性をネタにしている、ハラスメントを肯定的に描いていると受け取られうる表現はないか。

# 回答の形式
1. 全体の評価（5〜8行）：良い点と、最も直すべき点
2. 指摘の一覧（表）。重要度の高い順に並べる。

| No | 観点（A〜D） | 対象のカード（ID） | 重要度（高／中／低） | 問題 | 修正案（文言まで具体的に） |
|---|---|---|---|---|---|

   - 重要度「高」は、公開前に必ず直すべきもの（ルール違反、AdSense や炎上のリスク、意味が伝わらない）に限ってください。
   - 修正案は、文字数の制約を守った完成形の文言で書いてください。
3. 良いカード（3〜5枚）：IDと、良い理由を1行ずつ
4. 追加候補のネタ（観点A。5〜10件）：1行ずつ。カードの文面までは不要

# 注意
- 指摘の数を増やすことより、重要な指摘を確実に挙げることを優先してください。問題がないカードに無理に指摘を付けなくて構いません。
- 推測で書く場合は「推測」と明記してください。
```
